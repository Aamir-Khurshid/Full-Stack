# Full-Stack Projects by Aamir Khurshid

Welcome to the **Full-Stack** repository!  
This repo contains a collection of frontend and web development projects built with **HTML, CSS, and JavaScript** — showcasing various layouts, styling techniques, and small JavaScript apps.

---

## 🚀 What’s Inside

The repository includes multiple folders and example files, such as:

### 🗂️ Project Structure

- **Portfolio-2025/** – Personal portfolio website built with HTML/CSS/JS  
- **Space-Exploration/** – A themed project demonstrating layout and styling  
- **My Card/** – A small UI card component example  
- **MY-TOWN/** – A basic informational site about a town  
- **Google/** – Clone or practice layout inspired by Google Search UI  
- **File Path/** – Example structure for file or component paths  
- **FLEX Box** – Examples of Flexbox layout techniques  
- **Birthday-Wish/** – A small interactive birthday page  
- **assignment1.html**, **index.html**, **list.html**, **margin.html** – Example HTML practice files

> These files are mostly static HTML/CSS/JS demos meant for learning and showcasing layout skills. They can be opened directly in a browser to view each page.
